# 13 — PAR2 parity archives

- **Priority:** P2
- **Depends on:** [07](07-rar5.md) (integration point), crypto decision in [05](05-zip-encryption.md) (MD5/SHA-1)
- **Estimated effort:** 2–3 weeks
- **Crate:** `omnizip-par2`

## Goal

PAR2 (Parity Archive Volume 2): packet structure (main, file description,
slice, recovery), MD5 block-level corruption detection, verify without
unpacking, repair via Reed-Solomon over GF(2^16), configurable redundancy
0–100%.

## Ruby → Rust module map

| Ruby source | Rust module | LOC |
|---|---|---:|
| `formats/par2/` (packets, RS, verify, repair) | `packet.rs`, `reedsolomon.rs`, `verify.rs`, `repair.rs` | 4,567 |
