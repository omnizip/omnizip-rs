## Goal

ISO 9660 read/write: primary + supplementary volume descriptors, directory
records, Rock Ridge (SUSP entries: NM, PX, SL, etc.) and Joliet (UCS-2)
extensions, El Torito boot records (read).

## Verification notes (2026-08-26)

Dual-tree writer: PVD (ISO level-1 names) + Joliet SVD (UCS-2BE, escape
`%/E`), both trees carrying identical Rock Ridge areas (NM + PX + SL), so
either tree yields full metadata. SP+RR in root `.` records, path tables
L/M for both trees, PX carries POSIX type bits (`S_IFDIR`/`S_IFLNK`).
Oracles: bsdtar lists + extracts (file content, on-disk symlink), 7zz
lists, libarchive harness (modes 040555/100644/120644). Fixed:
SUSP-entry length byte offset (was reading the signature byte), SL
component walk (flags byte), M-path-table location is big-endian,
path-table size both endiannesses, volume-descriptor root record may
carry SU past the 34-byte field.
